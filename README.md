# 大世界 PCG 题库 v3.5

[打开题库](https://yuzi-huang.github.io/world-pcg-questionbank/#flow)

40个主题，每题两步：

1. 按世界地域生成参考图，每地域一张，统一自然中广角轻微俯视的环境镜头。
2. 根据整组地域图与精简后的题目要求制作连续PCG大世界。

题目有几个地域就生成几张主图，覆盖各自的地形、通路和地标。图片属于同一世界的不同地点，时代、风格、光照与连接一致。PCG合并重复条款，保留统一合同＋本题要求，篇幅目标为v3.4的约四分之三；最后一条可选使用或不使用Blender。两种版本都交付浏览器项目，不要求EXE。

支持总Prompt两版本复制、整包及单地域生图复制、PCG两版本复制、搜索和尺寸筛选。TXT可按版本下载，JSON包含两种版本的完整及PCG Prompt，以及全部单地域Prompt。详细规模研究和评测参考保留在分析页。

尺寸配比保持4×4 km 8题、8×8 km 24题、100×100 km 8题。当前交付是题库，尚未实际生图或生成场景。

由GitHub Pages发布，入口为独立运行的 `index.html`，无外部运行依赖。
