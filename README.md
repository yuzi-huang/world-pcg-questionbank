# 大世界 PCG 题库 v3.0

[打开题库](https://yuzi-huang.github.io/world-pcg-questionbank/)

保留40个主题，统一为两阶段：文字生成同一连续空间的3–4张参考图，再用通过检查的图片与世界Prompt生成PCG大世界。暂停纯文字直接生成PCG。

三个tab：流程与规模分析、文→图40题、图＋Prompt→PCG40题。后两个tab是同一批主题的前后步骤，共40个主题。尺寸分布为4×4 km 8题、8×8 km 24题、100×100 km 8题。

支持搜索、尺寸筛选、跨阶段跳转、整套及逐张Prompt复制、TXT/JSON导出和交接清单下载。默认四个视角；前三张足够时可省略第四张并记录原因。主图通过检查后，以其为条件生成补图；室内、室外分包。

当前交付为题面与待填写模板，尚未生成实际图片或PCG世界。图片约束局部核心区，世界面积和跨区关系由世界规划约束。

由GitHub Pages发布，入口为独立运行的 `index.html`，无外部运行依赖。
