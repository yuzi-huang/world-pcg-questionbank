# 大世界 PCG 题库 v3.3

[打开题库](https://yuzi-huang.github.io/world-pcg-questionbank/#flow)

40个主题，每题两步：

1. 根据设定与要求生成同一连续空间的3–4张图。
2. 根据生成的图与题目要求制作PCG大世界。

支持整题或分步复制、搜索、尺寸筛选、TXT/JSON导出。每题完整Prompt约4000字，覆盖专属场景、多视角、PCG、漫游与验收；仍只有两个步骤。详细研究与补充评测参考保留在分析页。

尺寸配比保持4×4 km 8题、8×8 km 24题、100×100 km 8题。当前交付是题库，尚未实际生图或生成场景。

由GitHub Pages发布，入口为独立运行的 `index.html`，无外部运行依赖。
