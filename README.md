# 大世界 PCG 题库 v3.4

[打开题库](https://yuzi-huang.github.io/world-pcg-questionbank/#flow)

40个主题，每题两步：

1. 根据设定与要求生成同一连续空间的3–4张图。
2. 根据生成的图与题目要求制作PCG大世界。

生图部分保留完整设定、四个自然语言镜头、交接与图包检查，直接开始生图。PCG采用完整统一合同＋本题专属要求，最后一条可选使用或不使用Blender；两种版本都交付浏览器项目，不要求EXE。题面不限字数，仍只有两个部分。

支持总Prompt两版本复制、生图独立复制、PCG两版本独立复制、搜索和尺寸筛选。TXT可按所选版本下载，JSON包含两种版本的完整及PCG Prompt。详细规模研究和评测参考保留在分析页。

尺寸配比保持4×4 km 8题、8×8 km 24题、100×100 km 8题。当前交付是题库，尚未实际生图或生成场景。

由GitHub Pages发布，入口为独立运行的 `index.html`，无外部运行依赖。
